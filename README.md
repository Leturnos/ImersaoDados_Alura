## 📖 Sobre o Projeto

Este projeto foi desenvolvido durante a **Imersão Dados Com Python** da Alura, um evento focado em análise e visualização de dados com Python utilizando bibliotecas como pandas e numpy e plotly. O objetivo principal foi aplicar técnicas de manipulação de dados para extrair insights e, ao final, construir uma aplicação web interativa para apresentar os resultados.

<img width="600" height="400" alt="image" src="https://github.com/user-attachments/assets/74ff49f8-97b5-4c9a-9ba5-1b878ab52387" />

## 🎯 Principais Tópicos Abordados

* **Manipulação e Tratamento de Dados**: Limpeza e transformação da base de dados utilizando `Pandas` e `Numpy`.
* **Visualização de Dados**: Criação de gráficos interativos e informativos com a biblioteca `Plotly`.
* **Desenvolvimento Web de Dados**: Construção e deploy de uma aplicação web para apresentar a análise de forma acessível com `Streamlit`.

## ✨ Tecnologias Utilizadas

* `Python`
* `Pandas`
* `Numpy`
* `Plotly`
* `Streamlit`

## 🚀 Como Executar Localmente

Siga os passos abaixo para rodar a aplicação na sua máquina.

### Pré-requisitos

* [Python 3](https://www.python.org/downloads/)
* [Git](https://git-scm.com/downloads)

### Passo a Passo

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/Leturnos/alura-data-immersion-python.git
    ```

2.  **Acesse a pasta do projeto:**
    ```bash
    cd alura-data-immersion-python
    ```

3.  **(Opcional, mas recomendado) Crie e ative um ambiente virtual:**
    ```bash
    # Criar
    python -m venv venv
    # Ativar (Windows)
    .\venv\Scripts\activate
    # Ativar (Linux/macOS)
    source venv/bin/activate
    ```

4.  **Instale as dependências:**
    ```bash
    pip install -r requirements.txt
    ```

5.  **Execute a aplicação Streamlit:**
    ```bash
    streamlit run aula4.py
    ```

6.  Acesse a aplicação no seu navegador através do link local que aparecerá no terminal (geralmente `http://localhost:8501`).
