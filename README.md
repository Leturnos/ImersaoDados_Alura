# O que foi essa imersão?

Durante a Imersão de Dados da Alura, durante as três primeiras aulas, aprendemos comandos em Python para manipular e tratar uma base de dados; na última, por meio de um código fornecido pelos professores, implementamos gráficos interativos relacionados à base de dados. Para acessar o site, clique no link: <a href="https://siteimersaodadosalura.streamlit.app/">Acessar site</a> e aguarde o Streamlit acordar (Ele adormece no plano gratuito).

🛠 Tecnologias
- Python
- Pandas
- Numpy
- plotly
- Streamlit
